# 旅游通 · 真实旅行地图

> 走到哪里，真实体验就记录到哪里。

旅游通是一款以现场体验证据为基础的旅游消费发现产品。帮助游客在陌生城市找到值得尝试的街头美食、景区周边小店、老街与夜市摊位，并通过有时间、有地点、有证据等级的真实体验记录，减少信息过时和消费踩坑。

## 当前阶段

**MVP：前端工程骨架与交互原型已提交，真实数据能力开发中。**

第一阶段聚焦旅游美食：景区、老街、古镇、步行街、夜市、小吃街、景区周边餐饮及街边摊。暂不扩展酒店、门票、旅行团等复杂业务。

## 核心原则

1. 真实优先：奖励有效贡献，不奖励好评或上传数量。
2. 证据分层：现场实拍、真实消费凭证、普通体验分别表达，不把定位或付款凭证当作真实性的唯一证明。
3. 时间敏感：价格、营业状态和体验评价必须带时间。
4. 一店一档：优先匹配既有商家/摊位档案，避免重复建档。
5. 公平表达：不因差评处罚用户，不允许商家购买好评或删除真实差评。
6. 隐私最小化：只收集完成业务所必需的数据，消费凭证应支持敏感信息遮挡。
7. 可验证交付：没有实际运行和测试，不宣称功能完成。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```
